## 🧱 How I Work

- **Reproducibility first:** pipelines are designed to be re-run (containerized environments, sequential stages, documented inputs/outputs).
- **Benchmarking, not black boxes:** methodological comparisons (stepwise/LASSO, SDM vs. OLS, sensitivity runs) are documented so results can be challenged and replicated.
- **R&D framing:** repositories are prototypes and applied research, not production consulting deliverables — see the scope notice below.
